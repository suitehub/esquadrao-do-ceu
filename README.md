# Esquadrão do Céu — Protótipo do Sistema do Clube

Protótipo navegável e responsivo do sistema de gestão do Clube de Desbravadores **Esquadrão do Céu** (unidades Águias, Fênix e Stelar).

- Site estático: abra `index.html` ou acesse o GitHub Pages do repositório.
- Logo oficial: salve como `assets/logo.png` (PNG 512x512, fundo transparente). Ver `assets/LEIA-ME.txt`.
- Sem build, sem dependências: HTML + CSS + JS em um único arquivo.

Deploy automático: push na `main` publica no GitHub Pages via Actions.
